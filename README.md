# Bank Marketing Customer Analytics

## Objective
Analyze 45,211 customer records to identify the factors associated with term-deposit subscription and provide business recommendations.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Performed
- Data Quality Assessment
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Executive Summary

## Key Insights
- Overall subscription rate: 11.7%
- Previous campaign success had the strongest association with subscription.
- Longer call durations were associated with higher conversion rates.
- Customers without housing loans consistently showed higher subscription rates.
